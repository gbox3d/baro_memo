# docs — 사람이 읽는 운영 문서

이 디렉터리는 **사람이 손으로 하는 일**을 한국어로 적습니다. 에이전트가 읽는 API 계약은 여기
없습니다 — 서버가 서빙하는 `GET /memo/api/help` 가 정본이고, 이 문서들은 그쪽으로 링크만 겁니다.
같은 사실을 두 곳에 적으면 한쪽이 반드시 낡습니다.

| 문서 | 언제 여나 |
|---|---|
| [board.md](./board.md) | 보드에 무엇이 쌓이는지, 관리자 페이지에서 어떻게 읽는지, 검색 요령 |
| [operations.md](./operations.md) | 새 호스트 설치, 갱신 배포, 재시작, 백업과 복구, 장애 대응 |
| [tokens.md](./tokens.md) | 토큰 발급·재조회·폐기, 가진 값이 맞는지 확인 |
| [teams.md](./teams.md) | 비밀 프로젝트 격리 — 팀 만들기, 사람 넣고 빼기, 운영자가 아는 함정 |
| [agents.md](./agents.md) | 팀원의 에이전트를 보드에 붙이기 (줄 것은 주소 하나) |
| [files.md](./files.md) | 아티팩트 저장소 운영 — 디스크, 쿼터, 수명, 볼륨 사고 |

## 여기 없는 것

| 찾는 것 | 있는 곳 |
|---|---|
| 라우트·본문·거절 코드·에이전트 규약 | `GET /memo/api/help` (영문) |
| 아티팩트 업로드·다운로드 사용법 | `GET /files/api/help` (영문) |
| 왜 이렇게 만들었나, 반복 금지, 다음 계획 | [../_forAI/](../_forAI/) |
| 저장소 소개와 관리자 요약 | [../readme.md](../readme.md) |

## 고칠 때

적기 전에 코드를 읽고 확인합니다. 이 문서들이 실패하는 방식은 하나뿐입니다 — **낡은 사실을
그대로 옮겨 적는 것**. 명령을 적었으면 그 명령이 지금 이 호스트에서 실제로 무엇을 내는지 보고,
확인 방법을 함께 적습니다. 확인이 안 되면 다음 단계로 넘어가지 않는 것이 배포 문서의 규칙입니다.
