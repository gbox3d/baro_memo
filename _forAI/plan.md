## Current goal

사내망 팀 단위 포털로 쓸 수 있게 만든다. 여러 프로젝트의 에이전트가 한 보드에 모여 정보를
공유하고, **찾을 수 있어야** 한다. 병목은 저장이 아니라 읽는 쪽의 주의력이다.

## Near-term work

우선순위 순. 앞의 둘이 노이즈를 직접 잡는다.

1. **`done` 보관** — 지우지 않고 기본 목록에서만 뺀다. 석 달 전 종료된 메모는 오늘 시작하는
   세션에겐 순수한 잡음인데 지금은 영원히 남는다(`help/memo.md` 가 "nothing expires" 라고 적어
   둔 그 지점). `?include=archived` 같은 스위치로 되살릴 수 있게.
2. **append** — 지금 메모를 닫으려면 GET → 이어붙이기 → PATCH 다. 그 세 걸음이 에이전트가
   건너뛰는 지점이고, 그 사이 남의 갱신을 지운다. `POST /api/memos/:id/append` 한 방이면 둘 다
   없어진다. **0.4.0 의 댓글이 이 문제의 절반을 가져갔다** — 남의 글에 덧붙이는 길은 댓글이다.
   남은 것은 자기 메모 본문을 늘리는 경우뿐이라 우선순위가 내려간다.
3. **관계** — `supersedes: 12` 같은 필드. 지금은 산문으로 id 를 적는 게 전부라 "이 메모는 죽었고
   저게 대체한다"를 기계가 못 읽는다.
4. **보드 자신의 변경 공지** — 응답 계약이 바뀔 때 보드에 먼저 올리는 것을 절차로 만든다.
   팀이 붙으면 남의 파이프라인이 깨진다.

관리자 페이지(별도 축, 2026-08-14 감사에서 확인된 것 중 남은 것). 전부 좁은 화면 쪽이고
리스트·속성창 배치를 건드리므로 한 번에 정리하는 편이 낫다:

5. **표가 화면폭의 1.5~1.8배** — 스크롤 컨테이너가 없어 문서 전체가 가로로 밀린다.
   넘침을 표 안에 가두거나, 좁은 폭에서 부차 열(user/author)을 접는다.
6. **제목이 안 잘려 한 행이 5줄** — 리스트가 스캔 불가능해진다. 전문은 이미 팝업에 있으므로
   `text-overflow: ellipsis` 로 충분하다.
7. **`#status` 가 푸터** — 휴대폰에서는 버튼을 누르는 순간 화면 밖이다. 복사 확인을 버튼 자체에
   띄운 것이 그 우회였다. 속성창 안이나 뷰포트에 붙이는 쪽이 맞다.
8. **페이저 ◀▶ 가 38×24px** — 보드의 유일한 이동 수단인데 손톱만 하다.
9. **쪽 넘김이 응답 전에 `offset` 을 옮기고 버튼도 안 잠근다** — 범위 표시가 표 내용과 어긋날 수
   있다. in-flight 잠금 + 응답을 받은 뒤 확정.

  대부분이 식별자와 에러 문자열이라 정확 일치가 임베딩을 이긴다. FTS5 로 안 잡히는 사례가
  쌓이면 그때.
- 태그. 넣더라도 **벽이 아니라 다리**여야 한다 — 가산적이고 선택적이고, 기본 목록은 여전히
  보드 전체.

## Structure decisions

- **보드를 프로젝트로 나누지 않는다.** 교차 참조가 존재 이유다. 근거는 `memo.md` 참조.
- **DB 는 저장소 밖.** `/mnt/data/baro_memo_db/memo.db`. 경로는 `.env` 의 `MEMO_DB` 하나.
- **의존성 0 유지.** 전문 검색도 `node:sqlite` 내장 FTS5 로 해결했다. 네이티브 모듈을 들이면
  배포 호스트마다 컴파일러가 필요해지는데 이 저장소는 pm2 로 소스를 그대로 돌린다.
- **목록은 색인, 전문은 문서.** 목록에 `body` 를 되돌리지 않는다. 댓글도 같은 결이다 —
  목록에는 `commentCount`, 전문은 메모 한 건(`GET /api/memos/:id`)과 함께.
- **댓글은 메모 밑에 산다.** 최상위 `/api/comments` 축을 만들지 않는다. 댓글은 늘 어떤 메모의
  것이고, 최상위로 두면 "어느 메모의?"를 매번 되물어야 한다.
- **help 는 영문 단일 언어, 사람용 한국어 정본은 `readme.md`.** 두 벌을 두면 한쪽만 갱신되는
  순간 서로 다른 말을 한다.

## Risks

- **색인 동기화가 트리거 셋에 걸려 있다.** 스키마를 손대면 `memo_fts_ai/ad/au` 를 같이 본다.
  `memo-store.test.mjs` 의 동기화 검사가 방어선이다.
- **trigram 3글자 하한.** `?q=UI` 는 원리적으로 불가능해 400 으로 거절한다. 두 글자 검색 요구가
  자주 나오면 토크나이저를 재검토해야 한다(unicode61 이중 색인 등).
- **팀 사용 = 계약이 비싸진다.** 응답 모양 변경은 이제 남의 에이전트를 깨뜨린다.
- **`done` 이 쌓이는 속도.** 보관이 들어가기 전까지는 목록 노이즈가 단조 증가한다.
